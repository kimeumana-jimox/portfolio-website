About

I'm a cybersecurity enthusiast who learns by building. On the defensive side I practise endpoint monitoring: reading Windows Security logs, writing PowerShell detections and automating them with Task Scheduler. Next I want to take that into SIEM tooling such as Wazuh and Splunk.

I also apply security to real problems around me. Paper visitor books at apartment gates leak people's names and ID numbers, so I'm building SecureGate to replace them with access control, MFA and audit trails. Event tickets get faked and resold, so I built Tikiti with tamper-proof QR check-in.

In both, access rules live in the database, every sensitive action is logged, and I test the defences with race and volume tests instead of trusting them.

  • Windows Failed Login Detector↗

    Security lab

    A lightweight intrusion-detection lab. A PowerShell script watches the Security log for failed logons (Event ID 4625), saves evidence and a screenshot, and raises a notification once a threshold is passed. Task Scheduler runs it automatically.

    • Event IDs 4625 & 4624
    • Evidence capture + alerting
    • Next: SIEM forwarding (Wazuh, Splunk)
