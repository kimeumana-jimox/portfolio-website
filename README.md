# Kimeu — Portfolio

Personal portfolio site: cybersecurity enthusiast, projects and skills. Burgundy and black, one static `index.html` with no build step.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)**.
The site is then served at https://kimeumana-jimox.github.io/portfolio-website/
